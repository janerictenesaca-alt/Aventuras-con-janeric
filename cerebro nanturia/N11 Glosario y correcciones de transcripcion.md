# N11 · Glosario y correcciones de transcripción

## Términos del dominio
| Término | Definición operativa |
|---|---|
| Agencia de viajes / agencia de servicios turísticos | Compañía registrada que puede intermediar y operar servicios turísticos (Reglamento de Operación e Intermediación). |
| Agencia dual | Agencia que ejerce como agencia de viajes internacional y operador turístico (Reglamento de Aventura, Art. 3). |
| Operador turístico / operadora | Persona jurídica registrada dedicada a la organización y operación directa de viajes y visitas. |
| Intermediación | Mediación, organización y venta de servicios turísticos entre consumidor y proveedores. |
| Guía local / nacional / de aventura | Clasificaciones del Reglamento de Guianza 2025 (ver [[N02 Marco legal Ecuador\|N02]]). |
| Catastro Turístico Nacional de Guías | Base de datos de guías con registro de turismo. |
| LUAF | Licencia Única Anual de Funcionamiento. |
| Plan de operación y contingencia | Documento técnico por modalidad (Reglamento de Aventura, Art. 10). |
| Consentimiento informado | Documento firmado por el turista que reconoce los riesgos. |
| PAAT | Permiso Ambiental de Actividad Turística (áreas protegidas). |
| Salida | Instancia de un tour con fecha, cupo, mínimo y proveedor. |
| Oferta | Un proveedor que opera una ruta. |
| Ruta canónica | Ficha única del producto; varios proveedores pueden ofertarla. |
| Take rate | Porcentaje del precio que retiene Nanturia. |
| Payout | Pago al proveedor tras el servicio. |
| Dossier de ruta | Paquete documental versionado de una ruta. |
| NAS | Almacenamiento conectado a la red («nube física»). |
| Chuchaqui | Resaca (coloquial ecuatoriano). |
