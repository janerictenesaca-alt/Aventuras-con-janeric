# Resúmenes del proyecto (TUTI)

Cada vez que escribes **TUTI**, Claude guarda aquí un resumen nuevo del trabajo.

- Un archivo por resumen, con fecha y hora: `YYYY-MM-DD_HHMM_resumen.md`.
- Los resúmenes viejos no se borran: son el historial y el respaldo.
- El más reciente también se copia a `HANDOFF.md` (raíz del repo), que es el que Claude lee al empezar una sesión nueva.
